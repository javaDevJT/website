# Discord Option Tailer

## Rule-Based Review of Discord Options Alerts

Discord Option Tailer collects configured Discord options alerts, normalizes their messages, and applies deterministic checks to supported formats. A dashboard tracks interpretations and review states, with optional model-assisted evaluation for other message formats.
